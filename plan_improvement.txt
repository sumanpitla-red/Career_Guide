Implementation Plan - Refactor Career Guidance Form Architecture
Refactor the current linear form structure into a hierarchical one where users can add multiple education levels, each containing its own Education, Exams, Scholarships, and Jobs details.

User Review Required
IMPORTANT

This is a major refactor of the state management and UI structure. The existing linear flow (Basic -> Edu -> Exam -> Scholar -> Job) will be replaced by a Basic Info section followed by a dynamic list of "Career Levels".
